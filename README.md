## 🚀 البدء السريع | Quick Start

### المتطلبات الأساسية | Prerequisites
- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- محرر نصوص (VS Code, Sublime Text, Atom)
- اتصال إنترنت (لتحميل المكتبات الخارجية)

### خطوات التنصيب | Installation Steps

```bash
# 1. انسخ ملفات المشروع
git clone [repository-url]

# 2. افتح مجلد المشروع
cd alaa-yaseen-art-gallery

# 3. افتح الموقع في المتصفح
# يمكنك فتح ملف index.html مباشرة في المتصفح
```

🎯 كيفية الاستخدام | How to Use

للفنان/المالك | For Artist/Owner

1. رفع الملفات على استضافة الويب المفضلة
2. تحديث المعلومات الشخصية في قسم "تعرف عليّ"
3. إضافة صور جديدة في مصفوفة artworks داخل ملف index.html

للزوار | For Visitors

1. تصفح المعرض والنقر على أي صورة للتكبير
2. معرفة الفنان من خلال قسم "تعرف عليّ"
3. الاتصال المباشر باستخدام أزرار الهاتف والواتساب

🔧 التخصيص والتعديل | Customization

🔄 تحديث المعلومات

```javascript
// تحديث معلومات الأعمال الفنية
const artworks = [
    "image1.jpg",
    "image2.jpg",
    // إضافة صور جديدة هنا
];
```

🎨 تعديل التصميم

```css
/* تغيير الألوان الأساسية */
:root {
    --primary: #b8860b;      /* اللون الذهبي */
    --primary-dark: #8b6914; /* الذهبي الداكن */
    --secondary: #1a1a1a;    /* الأسود الداكن */
}
```

📱 إضافة صور جديدة

1. رفع الصورة الجديدة إلى مجلد الصور
2. إضافة اسم الملف إلى مصفوفة artworks
3. تحديث الصفحة لرؤية التغييرات
